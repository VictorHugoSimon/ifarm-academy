# Changelog v0.67

## Added
- carregamento lazy por superfície;
- fallback acessível durante carregamento;
- skip-to-content global;
- foco visível consistente;
- suporte global a `prefers-reduced-motion`;
- gate de performance/acessibilidade no CI.

## Changed
- estilos de sessão passam a ser carregados junto ao módulo autenticado;
- portal e workspace deixam de ser imports eager no bootstrap.

## Unchanged
- regras acadêmicas, comerciais, LGPD, RBAC e multi-tenant;
- nenhuma migration nova;
- nenhum deploy em produção.
