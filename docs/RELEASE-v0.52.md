# RELEASE — iFarm Academy v0.52.0

A v0.52 transforma a preparação de STAGE em um contrato verificável. A Academy passa a considerar iFarm Core obrigatório para readiness em ambientes de homologação/produção e ganha um smoke test seguro que pode ser executado assim que os recursos exclusivos estiverem provisionados.

Nenhum deploy é executado por esta release. Nenhum secret real é versionado.

## Gate de merge
- TypeScript;
- testes unitários/Functions;
- 33 migrations e fixtures existentes;
- contrato offline de STAGE readiness;
- build.

## Promoção
Promover para `main` ou produção somente depois da homologação real descrita em `STAGE-HOMOLOGATION-v0.52.md` e aceite humano explícito.
